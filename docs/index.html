Where does your
research day go?

SciTime is a scientific activity monitor. It quietly sorts your screen time into coding with AI, writing papers, analysing data, making figures, running jobs on the cluster — and the browsing in between.

Get started Open the live demo ↗ ★ GitHub

Built for researchers

Generic screen-time apps tell you "Chrome: 6 hours". SciTime tells you how much of that was Overleaf, PubMed, your Streamlit app or YouTube.

🧠

Knows research tools

Overleaf, Zotero, MATLAB, RStudio, Jupyter, Fiji, FSLeyes, BioRender, Affinity — and AI assistants, split into coding and writing.

🖥️

Sees your terminal

An ssh session counts as cluster time, claude or codex in the front tab as AI-assisted coding.

⏱

Lives in the menu bar

Today's total at a glance. Click for each category, the top sites and how you are doing on your goals.

🎯

Goals and limits

"Write at least 4 h", "browse at most 1.5 h". A notification when you cross a limit and an evening digest by email.

📱

iPhone too

Optional Shortcuts automations add phone time to the same day — no app to install, no developer account.

✍️

Your own rules

One TOML file of regexes over app, URL, window title and terminal job. Edit it and past days are re-sorted too.

Private by design

SciTime has no server, no account and no network code. Your activity is a SQLite file on your Mac.

🔒

Stays on your Mac

Stored in ~/Library/Application Support/scitime, readable only by your user.

🚫

No screenshots, no keylogging

Only the name of the app in front, the active tab's address and the terminal job.

💤

Idle time ignored

Five minutes without keyboard or mouse and the clock stops.

Install in a minute

Needs macOS and uv.

# get it
git clone https://github.com/yongninglei/scitime
cd scitime
uv sync

# see a dashboard with made-up data
uv run scitime demo
# your own rules, then run at login
uv run scitime init
uv run scitime install-agent

# any time
uv run scitime report
uv run scitime dashboard
